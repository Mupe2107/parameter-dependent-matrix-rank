# Algorithm Documentation

## Theory Overview
This section provides an overview of the theoretical foundations of the algorithm.

## 4-Phase Algorithm Description
1. **Symmetry Constraint Extraction**: Matrix summetry condition A transpose must equal A.
2. **Linear System Construction**: Construction of linear system whose unknowns are the parameters of matrix that are to be found from the characteristic polynomial.
3. **Gaussian Elimination Solver**: Solver for the newly formed system.
